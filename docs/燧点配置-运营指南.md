# 燧点 · 运营配置与功能说明

## 文档信息
- 整理日期：2026-07-24
- 目标读者：运营 / 管理员
- 一句话说明：把网站的额度单位改成自定义积分「燧点」，用户用**人民币**充值，到账为**燧点**，兑换比例由你在后台设置（例如 1 元 = 1000 燧点）。

---

## 一、燧点是什么

- 「燧点」是展示给用户的积分单位，类似其它平台的「积分 / Credits」。
- 用户充值时看到并支付的是**人民币**，到账的是**燧点**。
- 用户余额、消费记录、账单等都以燧点显示。
- 模型的实际成本核算在系统内部仍以美元/额度进行，你无需关心，只需设置好兑换比例。

---

## 二、两个需要设置的比例（重要）

系统里有两个相互独立的比例，请分清楚：

| 名称 | 后台字段 | 含义 | 举例 |
| --- | --- | --- | --- |
| **每元充值单位数** | Units per CNY (Top-up) | 用户充 1 元人民币，得到多少燧点 | `1000` → ¥1 = 1000 燧点 |
| **每美元单位数** | Units per USD | 模型消费/展示时，1 美元折算多少燧点 | `7000` → 模型 $1 = 7000 燧点 |

- 「每元充值单位数」决定**用户花多少钱、拿多少燧点**。这是你最常调的。
- 「每美元单位数」决定**模型消费时扣多少燧点**，也影响利润空间。
- 建议关系：`每美元单位数 = 业务美元汇率 × 每元充值单位数`。
  例如业务按 `$1 = ¥7`、`¥1 = 1000 燧点`，则「每美元单位数」填 `7 × 1000 = 7000`。
  （若把「每美元单位数」调得更高，等于每消费 $1 扣更多燧点，即提高毛利。）

---

## 三、后台配置步骤

### 步骤 1：进入配置页
后台进入 **系统设置 → 计费设置 → 货币与展示**
（路由：`/system-settings/billing/currency`）

### 步骤 2：设置展示与兑换
| 设置项 | 建议填写 | 说明 |
| --- | --- | --- |
| 展示模式（Display Mode） | 自定义货币（Custom Currency） | 全站改为燧点展示 |
| 自定义货币符号（Custom Currency Symbol） | `燧点` | 显示在数字旁的单位 |
| **每元充值单位数**（Units per CNY, Top-up） | `1000` | **1 元 = 1000 燧点** |
| 每美元单位数（Units per USD） | `7000` | 模型 $1 = 7000 燧点（按需调整毛利） |

保存即可生效。

### 步骤 3：设置最低充值与预设金额
进入 **系统设置 → 计费设置 → 支付网关**：
- **最低充值金额**：按**人民币元**填写，`1` 表示最低充值 ¥1。
- **预设金额 / 折扣**：这里填的数字现在都按**人民币元**理解（例如填 `10 / 50 / 100` 表示 ¥10 / ¥50 / ¥100 的快捷档）。
- **各支付方式的「最低」**：也是按**人民币元**理解（例如微信设 `50` 表示微信最低充 ¥50）。

> ⚠️ 如果你之前是按「美元/额度」思路配过这些数字，切换到燧点后请按**人民币元**重新核对一遍。

---

## 四、配置后用户看到的效果

以 `每元充值单位数 = 1000`、`每美元单位数 = 7000` 为例：

- **充值页**：档位显示「燧点 10,000 / 支付 ¥10」「燧点 50,000 / 支付 ¥50」……自定义金额按人民币输入。
- **确认支付**：显示「获得 10,000 燧点 / 实付 ¥10.00」。
- **余额 / 账单 / 消费记录**：统一显示燧点。
- **模型消费**：例如一次调用成本 $0.01，会扣 `0.01 × 7000 = 70 燧点`。

---

## 五、常见问题与注意事项

1. **改了「每元充值单位数」会影响老用户已有燧点吗？**
   不会改变老用户账上燧点的**数量**。但它决定新充值的到账比例，请谨慎调整并提前公告。

2. **兑换码怎么设？**
   在兑换码管理里，配额直接按**燧点**填写（页面会标注单位为燧点），发放与到账都会正确换算，无需你手工折算。

3. **哪些还不支持按燧点充值？**（当前版本）
   - 目前**人民币充值（微信 / 易支付）已完整支持**。
   - **支付宝**由另一套系统处理，需另行确认。
   - **Stripe / Creem / Waffo** 等境外渠道**尚未适配燧点**，如需启用请先联系开发。
   - **订阅套餐**为独立功能，未纳入本次燧点改造。

4. **上线前请做一次实测**：用微信充 **¥1**，确认：
   - 订单记录显示「充值 1,000 燧点」；
   - 账户余额正好增加 **1,000 燧点**。
   两者都对即说明配置正确。若余额异常偏大，请联系开发检查（可能是数据库升级未生效）。

5. **小数问题**：燧点对用户按整数展示；内部有更细的精度，正常充值不会出现「差几个燧点」的可见误差。

---

## 六、一句话速查

> 想设「1 元 = N 燧点」→ 到「货币与展示」把**每元充值单位数**填成 N；
> 想调「模型消费贵不贵 / 毛利」→ 调**每美元单位数**；
> 预设金额、最低充值、各支付方式最低值 → 一律按**人民币元**填。
