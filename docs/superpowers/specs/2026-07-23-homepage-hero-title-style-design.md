# 首页首屏标题样式调整设计

## 目标

将首页首屏标题“大模型路由价值分发平台”的视觉权重略微降低，并让标题颜色与当前主题色保持一致。

## 方案

- 只修改 `web/default/src/features/home/components/sections/hero.tsx` 中的首页 `h1`。
- 响应式字号从 `36 / 48 / 60px` 调整为 `30 / 36 / 48px`。
- 移除标题现有的硬编码浅色颜色和深色模式颜色覆盖，改用 Tailwind 的 `text-primary`，使其跟随 `--primary` 主题变量。
- 保持标题文案、字重、行高、字距、布局和其他首页内容不变。

## 验证

- 检查变更只涉及目标标题样式。
- 运行前端类型检查。
- 运行与首页布局相关的测试；如测试环境可用，再执行前端构建验证。
